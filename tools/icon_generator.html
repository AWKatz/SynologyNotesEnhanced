🎯 Flutter Launcher Icons Master → assets/icons/

pubspec.yaml generates iOS + Android from these via flutter_launcher_icons. After exporting, run:
dart run flutter_launcher_icons
If you export app_icon_foreground.png (transparent), also set adaptive_icon_foreground: "assets/icons/app_icon_foreground.png" and adaptive_icon_background to your background hex in pubspec.yaml for a proper Android adaptive icon.

📱 iOS Manual Fallback → ios/Runner/Assets.xcassets/AppIcon.appiconset/

Usually not needed — flutter_launcher_icons regenerates these. Kept here in case you ever need to hand-place one.

🍎 macOS → macos/Runner/Assets.xcassets/AppIcon.appiconset/

🪟 Windows → windows/runner/resources/

Windows needs a single multi-size .ico, not PNGs. After exporting the sizes above, combine them, e.g.:
magick app_icon_16.png app_icon_32.png app_icon_48.png app_icon_64.png app_icon_128.png app_icon_256.png app_icon.ico
then replace windows/runner/resources/app_icon.ico.
